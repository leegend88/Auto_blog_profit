# Blogger Automation Flow

작성일: 2026-03-24

## 목표

`AI/생산성 도구` 주제로 키워드 선정부터 Blogger 초안 저장 또는 발행까지 자동화합니다.

## 전체 흐름

1. 스케줄러가 매일 정해진 시간에 실행
2. 키워드 후보 수집
3. 키워드 점수화 및 상위 후보 선정
4. 중복 주제 여부 확인
5. 제목과 아웃라인 생성
6. 본문, FAQ, 메타 설명 생성
7. 이미지 또는 썸네일 생성
8. 정책/품질 검사
9. Blogger 초안 업로드
10. 수익화 링크 삽입 준비
11. 로그 저장 및 다음 후보 대기

## 단계별 설명

### 1. 스케줄 실행

- 예: 매일 오전 9시
- 1회 실행 시 게시글 1건 생성

### 2. 키워드 후보 수집

수집 대상 예시:

- `챗GPT`
- `제미나이`
- `AI 회의록`
- `AI 문서 요약`
- `AI 번역`
- `AI 이미지 생성`
- `AI 자동화`
- `무료 AI 도구`

수집 방식:

- 사전 정의한 시드 키워드 기반 확장
- 최근 인기 키워드 목록 반영
- 기존 발행 글과 중복 제거

### 3. 키워드 점수화

점수 기준 예시:

- 검색 관심도
- 정보성 여부
- 상업성 여부
- 시즌성
- 중복 발행 위험
- 애드센스 적합성

예시:

- `챗GPT 사용법`: 높음
- `무료 AI 툴 추천`: 높음
- `AI로 돈 버는 법`: 중간
- `민감한 생성형 콘텐츠`: 제외

### 4. 중복 검사

검사 항목:

- 기존 블로그에 유사 제목 존재 여부
- 최근 30일 내 유사 키워드 발행 여부
- 검색 의도 중복 여부

### 5. 제목/아웃라인 생성

제목 예시:

- `챗GPT로 업무 시간을 줄이는 7가지 방법`
- `무료 AI 생산성 도구 10가지 비교`
- `제미나이 사용법: 초보자가 바로 쓰는 실전 예시`

아웃라인 구성:

- 문제 정의
- 도구 소개
- 사용 방법
- 장단점
- 추천 사용자
- FAQ

### 6. 본문 생성

생성 항목:

- SEO 제목
- 서론
- 본문 섹션
- FAQ
- 메타 설명
- 태그 후보

원칙:

- 과장 광고 문구 제한
- 허위 기능 설명 금지
- 실제 사용 맥락 중심 작성
- 너무 짧은 글 금지

### 7. 이미지 생성

초기 추천 방식:

- 텍스트 기반 썸네일 자동 생성
- 심플한 배경 + 제목 + 아이콘 조합

이유:

- 저작권 위험이 가장 낮음
- AI/생산성 주제와 잘 맞음

### 8. 품질/정책 검사

검사 항목:

- 금지 표현 포함 여부
- 선정성/과장성 여부
- 브랜드 오해 유발 여부
- 문장 반복 과다 여부
- 너무 기계적인 문체 여부

### 9. Blogger 업로드

업로드 방식:

- 기본값: 초안 저장
- 조건 충족 시: 예약 발행 또는 즉시 발행

업로드 데이터:

- 제목
- HTML 본문
- 라벨
- 메타용 요약 텍스트

### 10. 수익화 링크 삽입 준비

현재 기준:

- 1차는 AdSense 중심
- 추후 `쿠팡 파트너스` 링크 삽입 가능성을 고려

적용 후보:

- 생산성 관련 주변기기 추천 글
- 홈오피스 셋업 글
- 책상, 의자, 모니터암, 키보드, 마이크 등 제품형 콘텐츠

운영 원칙:

- 정보성 본문이 우선
- 제휴 링크는 과도하게 삽입하지 않기
- 광고성 문구보다 실제 사용 맥락 중심으로 배치
- 제휴 문구 고지 위치는 추후 운영 정책에 맞게 고정

### 11. 로그 저장

저장 항목:

- 실행 시각
- 선택 키워드
- 생성 제목
- 업로드 결과
- 검수 상태

## 초기 운영 권장안

- 하루 1포스트
- 초안 저장 후 수동 검수
- 검수 통과 글만 발행

## 추천 KPI

- 발행 수
- 노출 수
- 클릭 수
- 애드센스 승인 여부
- 게시글별 RPM 변화
